# Yoga Phong Thai

Next.js App Router landing page for Yoga Phong Thai, styled with Tailwind CSS.

## Commands

```bash
npm install
npm run dev
npm run build
npm run test:e2e
```

## Structure

- `src/app`: App Router layout, metadata, and route composition.
- `src/components/landing`: Landing page sections and reusable UI pieces.
- `src/data`: Typed page content and public asset references.
- `public`: Runtime images, brand assets, and landing media.
- `tests`: Playwright end-to-end coverage for the landing page.
- `docs/superpowers/plans`: Migration and implementation plans.
